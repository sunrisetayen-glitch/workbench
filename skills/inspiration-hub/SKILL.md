# inspiration-hub — 自媒体灵感笔记 skill

## 定位

为自媒体创作者设计的碎片笔记 → 分类整理 → 话题提取 → 跨平台分析 闭环。
数据存在浏览器 IndexedDB 中，与灵感工作台共用存储层。

## 三层数据模型

```
inbox/     →   topics/      →   outputs/
碎片捕获       自动分类整理       提取输出
```

- **inbox/** — 零散记录。一句话想法、语音转文字、粘贴的链接。每条自动提取关键词标签。
- **topics/** — AI 归并后的主题笔记。一个话题一条，聚合了 inbox 中相关内容。带 `[[关联话题]]` 交叉引用。
- **outputs/** — 按需提取的分析报告。格式：`YYYY-MM-DD-话题名-analysis`，包含原始笔记摘录 + 跨平台内容参考链接。

## 四种模式

| 模式 | 触发词 | 功能 |
|------|--------|------|
| **记录** | "记录" / "capture" / "记一下" | 碎片文字 → inbox，自动分词打标签 |
| **整理** | "整理" / "compile" / "归整" | inbox 未归类项 → 按话题合并到 topics |
| **提取** | "提取" / "query" / "找一下" | 按话题从 topics 提取所有相关笔记 |
| **分析** | "分析" / "analyze" / "参考" | 对提取结果，生成各平台搜索链接 + 内容方向建议 |

## 记录（capture）

输入：任意文字、链接、或两者混合。

1. 自动识别类型：纯文字 → `note`，含链接 → `ref`，标签列表 → `idea`
2. 用 Intl.Segmenter 分词提取关键词作为标签（3-8个）
3. 存入 inbox，生成 id + 时间戳
4. 返回：已记录 + 标签预览

## 整理（compile）

对 inbox 中未归类的项目：

1. 遍历所有 inbox 条目，按标签交集分组
2. 同标签 ≥2 条的合并为一个 topic
3. topic 标题从内容中自动提炼
4. 更新 topics 索引
5. 返回：新建/更新的 topic 列表

## 提取（query）

输入：话题关键词。

1. 在 topics 和 inbox 中全文搜索
2. 返回所有匹配条目，按相关度排序
3. 附带原始记录时间、标签

## 分析（analyze）

输入：提取出的一组笔记。

1. 提炼核心话题词（合并所有标签 + 标题分词）
2. 为每个平台生成搜索链接（复用 platforms.js）
3. 给出内容方向建议：这个选题在哪些平台更有潜力、适合什么形式（图文/短视频/长文）
4. 输出格式：`话题名 | 平台 | 建议方向 | 搜索链接`

## 与灵感工作台的集成

- 数据层共用 `db.js`（IndexedDB store: `notes`）
- 分析结果直接渲染到右侧「各平台参考」区域
- 左侧面板提供四个 tab 切换按钮
